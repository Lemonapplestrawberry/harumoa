하루모아는 회원가입이 없으며, 아기 사진을 포함한 모든 데이터는 기본적으로 사용자의 기기 안에만 저장됩니다. 광고·추적 도구를 사용하지 않으며, 어떤 정보도 제3자에게 제공하지 않습니다. 선택 기능인 클라우드 백업(하루모아+)을 직접 켠 경우에만, 사진이 암호화 전송되어 EU 리전 서버에 저장됩니다.

1. 처리하는 정보와 저장 위치

항목저장 위치목적
아기 이름(태명), 생년월일기기 내부생후 일수(D+n) 계산, 알림 문구
매일 촬영·등록한 사진기기 내부성장 기록 및 타임랩스 재생
앱 설정(알림 시간 등)기기 내부기능 제공
백업 데이터(사진·클립·아이 정보) — 백업을 켠 경우에만EU 리전 서버(Cloudflare R2)클라우드 백업·기기 변경 복원

하루모아는 계정·이메일·전화번호를 수집하지 않습니다. 유료 구독 결제는 Apple을 통해 처리되며, 하루모아는 결제 수단 정보를 열람할 수 없습니다.

2. 기기 권한 사용

  • 카메라 — 매일 한 컷 촬영에만 사용합니다.
  • 사진첩(읽기) — 지난 날짜의 사진을 가져올 때만 사용합니다.
  • 사진첩(저장) — "사진첩에 자동 저장" 옵션을 켠 경우에만 사용합니다.
  • 알림 — 매일 리마인더에만 사용합니다.

모든 권한은 해당 기능을 사용할 때 요청되며, 거부해도 나머지 기능은 정상 동작합니다.

3. 클라우드 백업 (선택 · 하루모아+)

  • 백업은 사용자가 직접 켠 경우에만 동작합니다. 켜지 않으면 어떤 데이터도 서버로 전송되지 않습니다.
  • 백업 대상: 사진·3초 클립·아이 이름·생년월일. 저장 위치: EU 리전(Cloudflare R2, GDPR 관할 지정).
  • 백업 접근에는 기기에서 생성된 복구 코드가 필요하며, 서버는 코드의 해시만 사용해 코드 자체를 저장하지 않습니다. 전송 구간은 TLS로 암호화됩니다.
  • Apple로 로그인(선택): 복구 코드를 Apple 계정에 연결해 보관하는 용도로만 사용하며, 이때 처리되는 정보는 Apple이 발급하는 익명 사용자 식별자뿐입니다. 이름·이메일은 요청하지 않습니다.
  • 백업 삭제: 앱을 삭제해도 서버 백업은 남습니다. 삭제를 원하시면 harumoa.help@gmail.com로 요청해주세요. 지체 없이 삭제합니다.

4. 보관 및 삭제

기기 데이터는 앱을 삭제하면 함께 삭제됩니다. ("사진첩에 자동 저장" 옵션으로 사진첩에 복사된 사본은 사용자의 사진첩에, 백업을 켠 경우 서버 백업은 3항에 따라 남습니다.)

5. 아동의 개인정보

하루모아의 사용자는 보호자(성인)입니다. 아기의 사진은 보호자가 직접 촬영·보관하며, 보호자가 백업을 켜지 않는 한 보호자의 기기를 벗어나지 않습니다.

6. 제3자 제공 및 광고

광고 네트워크, 분석(추적) SDK를 사용하지 않습니다. 백업 데이터의 저장에는 인프라 제공자인 Cloudflare(EU 리전)를 이용하며, 이 외 어떤 제3자에게도 정보를 제공하지 않습니다.
